# Team glossary

Answer with the definition below, word for word for the expansion, then one sentence of context.

| Term | Meaning | Context |
| --- | --- | --- |
| BHX | Blue Heron Expansion | The 2027 plan to open two new regional offices. |
| ORCA | Offline Review and Change Approval | The weekly meeting where risky changes are approved. |
| Q-Gate | Quality Gate 7 | The final checklist a release must pass before it ships. |
| Tidepool | Shared staging cluster | Where every team tests before Q-Gate. |

If the term is not in this table, say it is not in the glossary. Do not invent a meaning.
